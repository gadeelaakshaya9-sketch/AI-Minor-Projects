# Medical Insurance Cost Prediction — AIML Mini Project

## Overview
This end-to-end regression project explores the Medical Cost Personal Datasets and predicts insurance charges from age, sex, BMI, number of children, smoking status, and region.

## Dataset
- Kaggle: https://www.kaggle.com/datasets/mirichoi0218/insurance
- Public CSV mirror used by the notebook: https://raw.githubusercontent.com/stedy/Machine-Learning-with-R-datasets/master/insurance.csv

## Run in Google Colab
1. Download `Medical_Insurance_Cost_Prediction.ipynb`.
2. Open https://colab.research.google.com/
3. Choose **File → Upload notebook** and upload the `.ipynb`.
4. Choose **Runtime → Run all**.
5. If automatic dataset loading fails, download `insurance.csv` from the Kaggle dataset and upload it when prompted.
6. Review the generated charts and metrics. Write your final conclusion based on the actual results from your run.

## Project includes
- Problem statement and objectives
- Dataset loading and data understanding
- Missing-value, duplicate, and data-type checks
- Five EDA visualizations with observations
- Preprocessing with imputation, scaling, and one-hot encoding
- Linear Regression and Random Forest models
- MAE, RMSE, and R² evaluation
- Actual-vs-predicted, residual, and feature-importance plots
- Conclusion prompts, limitations, and future improvements

## Important
The notebook calculates results when run. Do not claim any specific performance metric until you have run it. This is an educational demonstration, not a tool for real insurance pricing or medical decisions.

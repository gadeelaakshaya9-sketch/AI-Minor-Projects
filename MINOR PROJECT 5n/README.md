# Medical Insurance Cost Prediction

## Project Overview
An AIML minor project to analyze medical insurance costs and predict insurance charges using machine learning.

## Dataset
[Kaggle Medical Cost Personal Dataset](https://www.kaggle.com/datasets/mirichoi0218/insurance)

## Project Workflow
- Data understanding and cleaning
- Exploratory data analysis
- Data visualization
- Linear Regression and Random Forest models
- Model evaluation and conclusion

## Tools
Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Google Colab
